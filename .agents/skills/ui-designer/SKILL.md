# PURPOSE

Create modern, clean, responsive UI.

---

# WHEN TO USE

- Build UI
- Improve UX
- Redesign screens

---

# PRINCIPLES

- Use shadcn/ui
- Use lucide-react
- Maintain visual hierarchy

---

# DECISION FRAMEWORK

If complex UI → split components  
If repeated UI → reuse component

---

# EXECUTION STEPS

1. Analyze feature
2. Define layout
3. Select components
4. Apply Tailwind styling

---

# OUTPUT FORMAT

- Component structure
- UI description
- Optional code

---

# ANTI-PATTERNS

- Inline CSS
- Inconsistent spacing
